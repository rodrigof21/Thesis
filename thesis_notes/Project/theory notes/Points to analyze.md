**Objective**: The goal is to analyse the various step response images and think about what points are worth considering for the identification

Some Ideas from Valério et. al (2025):

| **Point**                    | **Symbol** |
| ---------------------------- | :--------: |
| amplitude of the first peak  |   $y_1$    |
| time of the first peak       |   $t_1$    |
| amplitude of the second peak |   $y_2$    |
| time of the second peak      |   $t_2$    |
| time for $y(t) = 0,5$        | $t_{0,5}$  |
| its proportion               |   $\tau$   |
